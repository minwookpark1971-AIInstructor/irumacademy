      신청 방법

      1. 과정 선택

        관심 있는 과정의 「상세 보기」에서 일정·커리큘럼·수강료를 확인합니다.

      2. 신청서 작성

        「신청하기」에서 Google 로그인 후 신청서를 남깁니다. 열람은 로그인 없이 가능합니다.

      3. 입금

        신청 완료 화면에 안내되는 과정별 계좌로 수강료를 입금합니다.

      4. 확정 안내

        입금이 확인되면 수강이 확정되고 확정 안내 문자가 발송됩니다.

      외부 사이트 강의는 해당 사이트에서 직접 신청·결제합니다.
